Known cosmetic/behavioural notes (not blockers):
  - OFFSET logs only its distance in the command history, not each pick; a mistyped bare displacement such as 2010 gives
    "Point or option keyword required." instead of a displacement hint.
  - Layer Properties Manager shows some colours as raw RGB triples, others as names.
  - After EXTRUDE the SE Isometric view fits all drawing extents, so a small part can look small.
  - ViewCube compass-ring clicks from the Top view can land on a "Custom View" instead of a named view (unconfirmed).
  - Solids are not drawn on the Layout (paper) sheet; the sheet shows the 2D drawing.
  - PLINE width options are not supported (polylines carry no width). DXF colours are written as the nearest AutoCAD Color
    Index, so custom RGB layer colours change slightly after a DXF round trip; per-entity colours are not preserved.
  - The export dialog stays open until Close is clicked (it exists so downloads work in embedded browsers).
